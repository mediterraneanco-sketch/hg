# Host and Guest — სტუმარ-მასპინძელი — الضيف والمضيف
**Author / Narrative Adaptation:** Vakhtang Imerlishvili (ვახტანგ იმერლიშვილი)  
**Inspired by:** Vazha-Pshavela (ვაჟა-ფშაველა)

---

### About the Edition
**“Host and Guest”** is a contemporary narrative adaptation of Vazha-Pshavela’s timeless Caucasian epic poem exploring honor, hospitality, human conscience, and the sacred bond between host and guest across cultural boundaries.

### გამოცემის შესახებ (ქართულად)
**„სტუმარ-მასპინძელი“** — ვაჟა-ფშაველას უკვდავი პოემის თანამედროვე ნარატიული გადმოცემა ქართულ, ინგლისურ და არაბულ ენებზე. გამოცემა ეძღვნება ღირსების, სტუმარ-მასპინძლობისა და ადამიანობის უნივერსალურ იდეებს.
